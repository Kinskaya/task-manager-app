# 🚀 TaskManager — Приложение для управления задачами

Профессиональный интерактивный таск-менеджер, разработанный на стеке **React + TypeScript + Tailwind CSS** в рамках
строгого соответствия техническому заданию.

- **Live Demo:** `https://твоё-демо-на-vercel-или-netlify.com`

## 🛠️ Архитектура и Слой данных

Проект спроектирован по каноничным принципам **Separation of Concerns (Разделение ответственности)** и чистой
архитектуры React:

1. **Client-Server взаимодействие:** Слой данных полностью изолирован. Работа с бэкендом построена на базе связки *
   *Axios + React Query (TanStack Query)**. Интегрированы полноценные CRUD-мутации (`useCreateTask`, `useUpdateTask`,
   `useDeleteTask`).
2. **Фейковый бэкенд (MSW):** В качестве сервера используется библиотека **Mock Service Worker (MSW)**, которая
   перехватывает REST-запросы на уровне сетевого уровня браузера, эмулируя работу реальной базы данных в оперативной
   памяти сессии.
3. **Строгая типизация:** В кодовой базе полностью исключено использование типа `any`. Для контрактов отправки форм
   мутаций применены встроенные TypeScript-утилиты типов (например, `Omit<Task, 'id' | 'listId'>`).
4. **Управление темами:** Внедрён глобальный контекст `ThemeProvider` и кастомный хук `useTheme`, реализующие бесшовное
   переключение цветовых схем (Светлая / Тёмная / Системная через медиа-запросы `matchMedia`).

## 🧪 Тестирование и Качество кода

В проекте настроена автоматическая среда тестирования, покрывающая как алгоритмическую логику, так и визуальные
компоненты:

- **Юнит-тесты (Vitest):** Написано **8 юнит-тестов** на изолированный алгоритм ранжирования задач `sortTasks()` и
  **4 юнит-теста** на счётчики карточки.
- **Storybook Interaction Tests:** Интегрированы автоматические визуальные тесты взаимодействия компонентов Storybook на
  базе безголового браузера **Chromium** (общее количество успешных тестов в сборке — **17**).

## 📦 Быстрый запуск

### 1. Установка зависимостей

```bash
npm install
```

### 2. Запуск приложения в режиме разработки (Vite)

```bash
npm run dev
```

Приложение откроется локально по адресу `http://localhost:5173/`. Фейковый сервер MSW инициализируется в браузере
автоматически.

### 3. Запуск юнит-тестов и Storybook тестов

```bash
npm run test
```

Команда запустит тест-раннер Vitest и прогонит все 17 тестов приложения в консоли.

### 4. Сборка проекта в Production

```bash
npm run build
```
