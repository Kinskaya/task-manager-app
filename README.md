## 🛠️ Архитектура и Слой данных

Проект спроектирован по каноничным принципам **Separation of Concerns (Разделение ответственности)** и чистой
архитектуры React:

1. **Client-Server взаимодействие:** Слой данных полностью изолирован. Работа с бэкендом построена на базе связки *
   *Axios + React Query (TanStack Query)**. Интегрированы полноценные CRUD-мутации (`useCreateTask`, `useUpdateTask`,
   `useDeleteTask`).
2. **Фейковый бэкенд (MSW):** Реального бэкенда нет — его эмулирует библиотека **Mock Service Worker (MSW)**. Она
   перехватывает REST-запросы на сетевом уровне браузера и отвечает данными из `src/mocks/handlers.ts` в оперативной
   памяти сессии. Воркер инициализируется в `src/main.tsx` и бесшовно работает как в dev-режиме, так и в
   production-сборке на Live Demo.
3. **Строгая типизация:** В кодовой базе полностью исключено использование типа `any`. Для контрактов отправки форм
   мутаций применены встроенные TypeScript-утилиты типов (например, `Omit<Task, 'id' | 'listId'>`).
4. **Управление темами:** Внедрён глобальный контекст `ThemeProvider` и кастомный хук `useTheme`, реализующие бесшовное
   переключение цветовых схем (Светлая / Тёмная / Системная через медиа-запросы `matchMedia`).

## 🧪 Тестирование и Качество кода

В проекте настроена автоматическая среда тестирования, покрывающая как алгоритмическую логику, так и визуальные
компоненты:

- **Юнит-тесты (Vitest):** Написано **12 тестов** (8 — на алгоритм сортировки `sortTasks`, 4 — на логику счётчиков
  `countByStatus` и `calculateCompletionProgress`).
- **Storybook Interaction Tests:** Интегрировано **6 интерактивных историй** на базе `@storybook/test` с функцией
  `play` (5 тестов на форму логина: дефолтное состояние, отправка, валидация, ошибки API, состояние загрузки; 1 тест на
  строку `TaskRow` для проверки интерактивной смены статуса задачи).

Всего в автоматической сборке успешно проходит **18 тестов** по тест-кейсам.

## 📦 Быстрый запуск

### 1. Установка зависимостей

```bash
npm install
```

### 2. Запуск приложения в режиме разработки (Vite)

```bash
npm run dev
```

Приложение откроется локально по адресу `http://localhost:5173/`.

### 3. Запуск интерактивной витрины Storybook

```bash
npm run storybook
```

Компоненты и интерактивные сценарии `play` доступны по адресу `http://localhost:6006/`.

### 4. Запуск юнит-тестов и Storybook-тестов в консоли

```bash
npm run test
```

### 4. Сборка проекта в Production

```bash
npm run build
```
